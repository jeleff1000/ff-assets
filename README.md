# Fantasy Football Assets

Static assets for the Fantasy Football Analytics app.

## Contents

- `logos/transparent/` - NFL team logos with transparent backgrounds (173 files)
  - Historical logos from 1921-2025
  - Era-appropriate logos for relocated franchises (STL Rams, SD Chargers, OAK Raiders, etc.)

## Usage

Raw URLs:
```
https://raw.githubusercontent.com/jeleff1000/ff-assets/main/logos/transparent/{TEAM}_{YEARS}.png
```

Example:
```
https://raw.githubusercontent.com/jeleff1000/ff-assets/main/logos/transparent/NE_2000_Present.png
```
